## freopen

```cxx
freopen("input.txt", "r", stdin);
freopen("output.txt", "w", stdout);
// ...
fclose(stdin);
fclose(stdout);
```

## rdbuf

```cxx
ifstream in("input.txt");
ofstream out("output.txt");
// streambuf* cin_backup = cin.rdbuf();
// streambuf* cout_backup = cout.rdbuf();
cin.rdbuf(in.rdbuf());
cout.rdbuf(out.rdbuf());
```
