# 商店

## 思路

进行一个简单的遍历,如果后面一个商店的价格比当前商店的价格高,就买入当前商店的商品,并在后面一个商店卖出,如果后面一个商店的价格比当前商店的价格低,就卖出当前商店的商品.

注意本题交易次数是买入和卖出都算一次,所以最后的交易次数是持有状态改变的次数乘以2.

## 复杂度

时间复杂度：$O(n)$,其中$n$是商店的数量.因为我们只是进行了一次遍历.

int n;
void _()
{
    cin >> n;
    vector<ll> a(n);
    F(int, i, 0, n)
    cin >> a[i];
    ll profit = 0, transactions = 0;
    bool holding = false;
    F(int, i, 0, n - 1)
    if (a[i + 1] > a[i])
    {
        profit += a[i + 1] - a[i];
        if (!holding)
            holding = true, ++transactions;
    }
    else if (a[i + 1] < a[i])
        holding = false;

    cout << profit << ' ' << transactions * 2 << endl;
}
