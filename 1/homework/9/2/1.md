# 0-1 背包输出最优方案

## 思路

普通 0-1 背包只求最大价值时,只需要维护 `dp[i][j]` 或一维 `dp[j]`.如果还要输出选了哪些物品,就需要在状态转移时记录当前最优值是由哪个决策得到的.

可以使用二维 DP:

- `dp[i][j]` 表示只考虑前 `i` 个物品,背包容量为 `j` 时的最大价值.
- `pre[i][j] = 0` 表示状态 `(i,j)` 没有选择第 `i` 个物品,由 `(i - 1,j)` 转移而来.
- `pre[i][j] = 1` 表示状态 `(i,j)` 选择了第 `i` 个物品,由 `(i - 1,j - w[i])` 转移而来.

转移结束后,从 `(n,V)` 倒推:

- 如果 `pre[i][j] = 1`,说明最优方案中选择了物品 `i`,然后令 `j -= w[i]`.
- 如果 `pre[i][j] = 0`,说明没有选择物品 `i`.
- 每次都令 `i -= 1`,直到 `i = 0`.

这样倒推出的所有物品就是一组最优解.如果存在多组最优解,在价值相等时按照固定规则记录即可,例如优先不选或优先选.

## 伪代码

```text
for i = 1..n:
    for j = 0..V:
        dp[i][j] = dp[i - 1][j]
        pre[i][j] = 0

        if j >= w[i] and dp[i - 1][j - w[i]] + c[i] > dp[i][j]:
            dp[i][j] = dp[i - 1][j - w[i]] + c[i]
            pre[i][j] = 1

ans = empty list
j = V
for i = n..1:
    if pre[i][j] == 1:
        add i to ans
        j = j - w[i]

reverse(ans)
output ans
```
