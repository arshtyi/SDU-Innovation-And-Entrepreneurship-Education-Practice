# 多重背包

## 思路

多重背包中第 `i` 种物品最多选 `m_i` 个,体积为 `w_i`,价值为 `v_i`.朴素转移为:

$$
dp[j] = \max_{0 \le k \le m_i,\ k w_i \le j}(dp_{old}[j - k w_i] + k v_i)
$$

为了把每种物品的转移优化到 $O(V)$,可以按容量对 `w_i` 取模分组.对于同一个余数 `r`,容量只会在

$$
r,\ r+w_i,\ r+2w_i,\ ...
$$

之间转移.设当前容量为 `k`,候选的旧容量为 `x`,则选取数量是 `(k - x) / w_i`,转移值为:

$$
dp_{old}[x] + \frac{k - x}{w_i} v_i
$$

对于固定的 `k`,只需要在最近 `m_i` 个同余容量中找最大候选值.因此可以用单调队列维护这些候选状态:

- 队首保存当前窗口内最优的旧状态.
- 当 `k - 队首容量 > m_i w_i` 时,说明选取数量超过限制,弹出队首.
- 插入当前旧状态前,把队尾中不可能成为最优的状态弹出,保持队列单调.
- 用队首更新 `dp[k]`.

这样每个容量最多进队、出队一次,每种物品的复杂度为 $O(V)$.

## 复杂度

时间复杂度: $O(NV)$

## 代码

```cpp
#include <bits/stdc++.h>
#include <deque>
using namespace std;
#define fi first
#define se second
#define F(T, i, a, b) for (T i = (a); i < (b); ++i)
#define FF(T, i, a, b) for (T i = (a); i <= (b); ++i)
#define R(T, i, a, b) for (T i = (a); i > (b); --i)
#define RR(T, i, a, b) for (T i = (a); i >= (b); --i)
#define all(x) (x).begin(), (x).end()
#define rall(x) (x).rbegin(), (x).rend()
#define allab(x, a, b) (x).begin() + (a), (x).begin() + (b)
#define rallab(x, a, b) (x).rbegin() + (a), (x).rbegin() + (b)
#define pb push_back
#define eb emplace_back
#define pf push_front
#define ef emplace_front
using ll = long long;
using ull = unsigned long long;
using pii = pair<int, int>;
const int INF = 0x3f3f3f3f;
const ll LLINF = 0x3f3f3f3f3f3f3f3f;
const int M1 = 1e9 + 7, M2 = 998244353;
#define endl '\n'
#define local freopen("data.in", "r", stdin)
#define locall freopen("data.in", "r", stdin), freopen("data.out", "w", stdout)
// #define int ll
using pil = pair<int, ll>;
const int N = 1e4 + 10;
int n, V;
ll dp[N];
void _() {
    cin >> n >> V;
    FF(int, i, 1, n) {
        int mi, wi, vi;
        cin >> wi >> vi >> mi;
        int dj = mi * wi;
        F(int, j, 0, wi) {
            deque<pil> dq;
            dq.eb(j, dp[j]);
            for (int k = j + wi; k <= V; k += wi) {
                if (!dq.empty() && k - dq.front().fi > dj)
                    dq.pop_front();
                while (!dq.empty() && dq.back().se + (k - dq.back().fi) / wi * vi <= dp[k])
                    dq.pop_back();
                dq.eb(k, dp[k]);
                dp[k] = max(dp[k], dq.front().se + (k - dq.front().fi) / wi * vi);
            }
        }
    }
    cout << dp[V] << endl;
}
signed main() {
    // local;
    cin.tie(0), cout.tie(0), ios::sync_with_stdio(0);
    int T = 1;
    // cin >> T;
    while (T--)
        _();
    return 0;
}
```
